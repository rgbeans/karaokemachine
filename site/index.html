From download to singing

  1. Download the .json map package.
  2. Open KaraokeMachine → Library → Maps → Import Map File.
  3. If the audio is not already local, KaraokeMachine downloads it from the map's source link and separates the stems.
  4. Maps marked NO AUDIO are chart-only silent scores; nothing is downloaded.
  5. Sing it. The mapping is now playable locally.
